# STET + BPSC TRE Study Dashboard

A private study dashboard for a 25-day Bihar STET Computer Science sprint and follow-up BPSC TRE preparation.

## Features
- Daily 6-hour timetable and 25-day checklist
- Computer Science syllabus tracker
- Focus timer
- Mock-test score tracker and mistake notebook
- Flask backend with password-protected server-side progress storage
- SQLite database and Render Blueprint configuration

## Deploy on Render
1. Create a new **Blueprint** in Render and connect this repository, or create a Web Service from it.
2. Build command: `pip install -r requirements.txt`
3. Start command: `gunicorn app:app`
4. Set `DASHBOARD_PASSWORD` to a strong password you choose. `SECRET_KEY` is generated by the included Render Blueprint.
5. The included `render.yaml` configures a persistent disk for SQLite. Check Render's current plan/pricing for persistent-disk availability.

## Run locally
```bash
pip install -r requirements.txt
```
Set environment variables `SECRET_KEY` and `DASHBOARD_PASSWORD`, then run `python app.py`.
